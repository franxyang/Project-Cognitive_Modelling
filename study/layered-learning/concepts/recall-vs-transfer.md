# What it means

`Recall` is retaining or reproducing learned content.
`Transfer` is using learned structure in a new context.

# Why it matters for my project

The model should not treat all learning outcomes as equally sensitive to fragmentation.
Transfer is the main reason to care about preserved relations across segments.

# What it is often confused with

- immediate memory performance
- general learning success as one single outcome
- test difficulty alone
