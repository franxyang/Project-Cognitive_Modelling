# What it means

Cognition may appear limited not only because of hard constraints, but because allocating more resource has a cost, so behavior can reflect an optimal trade-off.

# Why it matters for my project

This concept is the main bridge from cognitive theory to constrained optimization.
It legitimizes writing capacity-limited processing as an objective rather than only as a verbal bottleneck.

# What it is often confused with

- perfect rationality
- assuming cognition is optimal in every respect
- fixed resource-budget models
