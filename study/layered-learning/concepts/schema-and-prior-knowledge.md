# What it means

Prior knowledge changes how demanding information is because familiar material can be processed as larger learned units rather than as many separate novel elements.

# Why it matters for my project

This is the main justification for `r_j`.
Without prior knowledge, the model would treat complexity as fixed when CLT says it is learner-relative.

# What it is often confused with

- intelligence or general ability
- objective task difficulty
- simple memory strength without structural organization
