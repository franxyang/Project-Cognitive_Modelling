# Core idea

Element interactivity refers to the number and strength of information elements that must be coordinated simultaneously for understanding.

# Why it matters here

This is the most important CLT concept for translating your project into mathematics.
It is the natural bridge from verbal complexity language to node-level and relation-level cost terms.

# Key distinctions

- number of elements versus interaction among elements
- task difficulty versus task complexity
- objective structure versus learner-relative complexity

# Modeling implications

- `q_j` can represent element-level complexity
- `w_uv` can represent coordination demand between elements
- `I_i` should increase with both local complexity and simultaneous interaction
