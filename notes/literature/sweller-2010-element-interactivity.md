# Core claim

Sweller argues that element interactivity is the common mechanism underlying intrinsic load and also much of extraneous load, while germane load should be treated not as an independent source of load but as the working-memory resources devoted to handling intrinsic load.

# Relevance to my project

This is the strongest direct theoretical precursor for the core structure of the model.
It supports:

- `I_i` as depending on simultaneously coordinated elements rather than raw quantity alone,
- `E_i` as avoidable interaction induced by instructional design,
- `P_i` as the remaining goal-relevant resources available for essential processing.

# Constructs and definitions

- `element interactivity`: the number of elements that must be processed simultaneously for understanding,
- `intrinsic load`: complexity fixed by the material and learner knowledge level,
- `extraneous load`: load created by instructional procedures that increase unnecessary simultaneous processing,
- `germane load`: not a separate load source, but the resources devoted to intrinsic processing.

# Method or formal approach

This is a theoretical synthesis paper.
Its value is conceptual clarification, not empirical estimation.

# Useful evidence

- Sweller explicitly states that low-interactivity material can involve many elements yet impose low working-memory load if those elements can be learned independently.
- He argues that intrinsic load changes with learner knowledge because what counts as a single element depends on prior knowledge and schema development.
- He also argues that extraneous load can be analyzed through the same lens of element interactivity when instructional design forces unnecessary simultaneous processing.
- A central move for this project is his claim that overall cognitive load is determined by intrinsic plus extraneous load, while germane load is the resources available for intrinsic processing.

# Limitations

The paper gives a strong conceptual scaffold but still does not formalize:

- a numerical representation of element interaction,
- a graph structure over elements,
- an optimization rule for partitioning or resource allocation.
