# Core claim

Sweller argues that conventional problem solving, especially via means-ends analysis, can consume so much limited cognitive processing capacity that it interferes with schema acquisition rather than promoting it.

# Relevance to my project

This is the origin point for the proposal's basic logic that processing burden and learning are not the same thing.
It supports:

- a capacity-limited bottleneck behind the model,
- the distinction between problem solving activity and genuine learning,
- the idea that instructional design can change how much capacity remains for schema acquisition.

# Constructs and definitions

- `schema`: a structure that lets the learner recognize problem states and appropriate moves,
- `means-ends analysis`: a strategy that works by reducing differences between the current state and the goal state,
- `cognitive load`: discussed here as heavy use of limited cognitive processing capacity before later CLT categories are stabilized.

# Method or formal approach

The paper combines theoretical argument, a computational model, and experimental evidence.
Its key comparison is between conventional goal-directed problems and nonspecific-goal variants that reduce search burden.

# Useful evidence

- Sweller argues that the cognitive processes needed for conventional problem solving overlap insufficiently with those needed for schema acquisition.
- He explicitly claims that means-ends analysis uses substantial cognitive processing capacity for goal attainment, leaving less available for learning.
- The paper reports evidence that nonspecific-goal conditions improve learning-relevant recall of problem structure and solution characteristics.
- A key transferable claim is that goal attainment and schema acquisition may be distinct and sometimes incompatible processes.

# Limitations

This paper is foundational but pre-dates the later intrinsic-extraneous-germane clarification.
It does not yet provide:

- a differentiated load taxonomy,
- a graph or network representation of problem structure,
- or an explicit optimization framework.
