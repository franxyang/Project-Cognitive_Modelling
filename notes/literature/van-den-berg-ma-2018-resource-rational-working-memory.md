# Core claim

van den Berg and Ma propose that working-memory allocation is chosen to minimize a weighted combination of behavioral error cost and neural encoding cost, rather than being determined by a fixed resource budget.

# Relevance to my project

This is the best paper in the current set for defending the move from verbal capacity language to constrained optimization.
It helps justify:

- treating capacity as allocable rather than strictly fixed,
- using an explicit objective that trades performance against resource cost,
- and allowing the total invested resource to vary with task demands instead of assuming a constant budget.

# Constructs and definitions

- `resource-rationality`: cognition trades off task performance against resource expenditure,
- `behavioral cost`: error-related performance loss,
- `neural cost`: cost of investing encoding resources,
- `optimal allocation`: the resource vector that minimizes total expected cost.

# Method or formal approach

The paper gives an explicit normative model.
Its key move is to define total cost as behavioral cost plus a weighted neural cost, then optimize over resource allocation rather than assume a hard fixed budget.

# Useful evidence

- The paper explicitly argues that apparent working-memory limitations may arise from rational cost minimization rather than only hard constraints.
- It allows total invested resource to vary non-monotonically with set size.
- It shows that optimal policy may involve encoding only a subset of task-relevant items when resource expenditure is costly.
- For this project, the strongest transferable idea is not the visual-memory domain itself but the structure of the optimization problem.

# Limitations

This is not a cognitive load theory or instructional-design paper.
It does not model:

- structured relations among information elements,
- intrinsic versus extraneous load distinctions,
- or instructional partitioning and coherence loss.
