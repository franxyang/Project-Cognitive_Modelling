# Cognitive Modelling Project

This workspace is set up to support a theory-first project on cognitive processing under working-memory constraints.

Use the repository root as your Obsidian vault. Keep Zotero as the source of truth for bibliographic data, and use Codex to help turn notes into structure, comparison tables, and draft text.

## Project map

- `memory.md`: compressed project memory for future turns
- `docs/proposal-skeleton.md`: the current proposal skeleton in Markdown
- `docs/project-brief.md`: a concise interpretation of the project's theoretical core
- `docs/workflow.md`: the recommended `Codex + Zotero + Obsidian` workflow
- `notes/literature/`: one note per paper
- `study/layered-learning/`: learning roadmap, concept notes, and reading artifacts hub
- `notes/modeling/`: formal assumptions, derivations, variants, and open questions
- `notes/templates/`: reusable note templates
- `manuscript/`: proposal and later preprint drafts
- `references/`: exported bibliography files from Zotero if you decide to sync them here

## Working principle

`Zotero` answers "what is the source?"

`Obsidian` answers "how does it fit the argument and the model?"

`Codex` answers "how do these pieces become a literature review, proposal, and manuscript?"
