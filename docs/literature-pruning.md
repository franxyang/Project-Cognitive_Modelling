# Literature Pruning

## Goal

This file records which papers should remain central, which should be archived from the active theory-only working set, and which would be safe to remove only if the project is kept strictly theory-first.

This is a pruning document for the current project scope.
It is not a blanket judgment on the papers themselves.

## Rule

- `keep-core`: directly supports the formal theory paper
- `keep-secondary`: useful for validation, positioning, or later expansion, but not central
- `archive-from-active-set`: keep in Zotero, but remove from the current active reading/writing set if you want a lean theory corpus
- `hard-delete-candidate`: safe to remove only if you are certain you do not want neuroscience or empirical validation paths in this project

## Archive from active theory-only set

These are the first papers to remove from the active writing set if you want a cleaner theory corpus:

- A systematic review of eye tracking research on multimedia learning
- Cognitive load in multimedia learning environments: A systematic review

Reason:

- they are mostly application and process-measure context,
- they do not define the main formal problem,
- and they do not sharpen the mathematical model much.
