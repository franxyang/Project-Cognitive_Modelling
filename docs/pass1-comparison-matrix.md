# Pass 1 Comparison Matrix

This matrix consolidates the nine backbone papers for the first round of literature review and proposal writing.

## How to use it

Use this file when you need to answer one of these questions quickly:

- Which paper justifies the optimization move?
- Which paper best supports a specific variable in the model?
- Which paper is background only, and which one actually constrains the formulation?

## Matrix

| Paper | Main role | Strongest contribution to the model | Best use in proposal | Limitation |
| --- | --- | --- | --- | --- |
| Sweller (1988) | Origin of the learning-vs-problem-solving distinction | Supports the claim that heavy problem-solving search can consume capacity needed for schema acquisition | Use in the gap and motivation sections to argue that solving and learning are not the same process | Pre-dates the later differentiated load framework and has no formal structural representation |
| Sweller (2010) | Core CLT mechanism paper | Best direct support for `I_i`, `E_i`, and the idea that `P_i` is residual capacity available for essential processing | Use in the formal framework section as the main conceptual predecessor of the cost structure | Conceptual only; no graph, no optimization, no estimation procedure |
| Sweller, van Merrienboer, and Paas (2019) | Updated cognitive architecture | Strongest support for `r_j`, schema effects, and germane resources as redistribution | Use to connect working memory, long-term memory, prior knowledge, and instructional design | Broad integrative review, not a model specification |
| Chen, Paas, and Sweller (2023) | Task complexity clarification | Best support for interpreting `w_uv`, interaction-based complexity, and learner-relative complexity | Use when defining task complexity and distinguishing complexity from mere difficulty | Stops short of a mathematical objective or graph model |
| Baddeley (1992) | Classic working-memory background | Supports the existence of a limited, structured temporary processing system behind `C_i` | Use for foundational background on working memory architecture | Classical architecture, not a flexible resource-allocation account |
| Ma, Husain, and Bays (2014) | Resource view of working memory | Supports treating `C_i` as allocable and graded rather than purely slot-based | Use to justify moving from fixed-capacity language to resource-allocation language | Not an instructional-design or CLT paper |
| van den Berg and Ma (2018) | Normative optimization precedent | Best support for explicit cost trade-offs and optimization under limited resources | Use to defend the legitimacy of constrained optimization in a cognition paper | Domain is visual working memory, not instructional segmentation |
| Anmarkrud, Andresen, and Braten (2019) | Conceptual and measurement critique | Supports the claim that CLT-based multimedia work often under-specifies working memory and measurement | Use in the literature-gap section to justify a stronger theory-measurement bridge | Focused on multimedia-learning literature rather than all CLT research |
| Sawicka (2008) | Internal formal-model precedent | Best support for saying that mathematical formalization is already legitimate inside CLT research | Use to position your project as a stronger and more structured formalization, not a category break | Generic simulation model, not a graph-partition or optimization account |
