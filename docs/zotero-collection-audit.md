## Immediate workflow implication

For this project, the first pass should not aim to summarize every paper equally.
It should answer four questions:

- What exactly is the theoretical gap in current cognitive load work?
- Which papers justify modeling load as a structured, capacity-limited system?
- Which papers help define variables such as complexity, connectivity, and novelty?
- Which papers matter only for later validation and should stay secondary for now?
