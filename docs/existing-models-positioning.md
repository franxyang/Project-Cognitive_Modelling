# Existing Models Positioning

## Why this file exists

This file positions the current project against the most relevant existing theory and modeling traditions.
Its purpose is to prevent two common mistakes:

- claiming false novelty when there are already adjacent formal models,
- or underselling the project by treating it as only a restatement of cognitive load theory.

## The short answer

There is no existing paper in the current set that already gives your exact model.

What already exists is a set of partial neighbors:

- verbal cognitive load theory,
- one direct CLT formalization,
- formal working-memory allocation models,
- coherence and comprehension models,
- and rational chunking or compression models.

Your project is best positioned as a synthesis that imports stronger formal tools into a CLT-shaped problem that is still under-formalized.

## The closest existing lines

### 1. Cognitive load theory

Best anchors:

- Sweller (1988)
- Sweller (2010)
- Sweller, van Merrienboer, and Paas (2019)
- Chen, Paas, and Sweller (2023)

What this line already gives:

- capacity-limited processing,
- intrinsic versus extraneous load,
- element interactivity,
- learner-relative complexity,
- prior knowledge as a major moderator.

What it does not yet give:

- a graph-structured representation of task information,
- a clear objective function,
- an optimization-based account of segmentation,
- or an explicit penalty for loss of cross-element structure.

### 2. Formal CLT precedent

Best anchor:

- Sawicka (2008)

What this line already gives:

- proof that formalizing CLT is a legitimate move inside the field,
- dynamic modeling rather than purely verbal theorizing.

What it does not yet give:

- graph structure,
- partition optimization,
- an explicit distinction between local relief and global structural loss.

### 3. Resource-rational and normative working-memory models

Best anchors:

- van den Berg and Ma (2018)
- Yoo, Klyszejko, Curtis, and Ma (2018)
- Jakob and Gershman (2023)

What this line already gives:

- constrained optimization under limited memory resources,
- strategic allocation,
- fidelity-cost or rate-distortion trade-offs,
- strong mathematical precedent for treating capacity limits normatively.

What it does not yet give:

- instructional content structure,
- element interactivity in the CLT sense,
- segmentation over semantically related information,
- learning outcomes like recall and transfer as the main target.

### 4. Coherence and comprehension models

Best anchor:

- Kintsch (1994)

What this line already gives:

- a serious account of coherence,
- the distinction between surface/text memory and usable understanding,
- strong support for the role of prior knowledge in integrating structure.

What it does not yet give:

- a capacity-allocation objective,
- an optimization account of segmentation,
- or a direct bridge to CLT variables such as intrinsic and extraneous cost.

### 5. Rational chunking and compression models

Best anchor:

- Nassar, Helmers, and Frank (2018)

What this line already gives:

- chunking as adaptive compression,
- a trade-off between representational efficiency and fidelity,
- strong support for treating limited-capacity representation as a design problem.

What it does not yet give:

- relational graph structure over instructional elements,
- a distinction between presentation-induced cost and structural cost,
- or a learning-theory framing.

## The clearest novelty claim

The project is not novel because it is the first formal model of limited cognition.
That claim would be weak.

The project is novel because it combines four things that are usually separated:

1. CLT-style intrinsic and extraneous cost,
2. graph-structured element interactivity,
3. segmentation as an explicit optimization problem,
4. and structural preservation as a distinct quantity that matters for downstream learning.

In compact form:

`existing models optimize memory fidelity or resource allocation; your model optimizes the partitioning of structured instructional information under capacity limits.`

## What to say carefully

Avoid claiming:

- that no one has formalized cognition under capacity limits,
- that no one has modeled working memory normatively,
- or that no one has linked coherence and learning.

Instead claim:

- mainstream CLT remains comparatively under-formalized,
- existing formal memory models rarely target structured instructional segmentation,
- and coherence-preservation is not usually built into CLT-style optimization accounts.

## Practical manuscript use

Use this positioning when writing:

- the literature gap paragraph,
- the transition from review to model statement,
- and the proposal contribution section.

The safest one-paragraph version is:

Current cognitive load theory provides the right problem space but remains mostly verbal at the point where task structure, segmentation, and learning consequences need explicit formal treatment. Existing formal working-memory models show that optimization under capacity limits is theoretically legitimate, but they typically target memory fidelity, precision, or resource allocation rather than the partitioning of structured instructional information. Coherence-based comprehension models explain why preserving relations matters for understanding and transfer, but they do not provide a CLT-style cost framework. The proposed model contributes by integrating these lines into a graph-structured optimization account of intrinsic cost, extraneous cost, goal-relevant processing, and connection loss.
