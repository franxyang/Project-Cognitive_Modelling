# Project Memory

## Project identity

- project: theory-first cognitive modelling paper
- current scope: literature review -> proposal -> possible theory/preprint
- current decision: do **not** center the project on designing or running an experiment
- current model idea: cognitive processing under limited working-memory capacity as a constrained optimization problem over structured information

## Core model objects

- `A`: information elements
- `q_j`: element complexity
- `w_uv`: connection strength / coordination requirement
- `r_j`: residual novelty after prior knowledge
- `Pi`: partition of the information set into segments
- `C_i`: effective processing capacity in a segment
- `E_i`: extraneous processing cost
- `I_i`: intrinsic processing cost
- `P_i`: remaining goal-relevant processing
- `L(Pi)`: connection loss caused by partitioning

## Main project interpretation

This is not primarily an experiment-first educational study.
It is mainly a formal theory paper with cognitive load theory as background and optimization over structured information as the main contribution.

The empirical literature matters mainly for:

- motivating the gap,
- constraining construct definitions,
- and sketching a possible validation path.

It should not dominate the manuscript.
